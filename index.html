⚠️ Foram encontrados erros na planilha

Os registros com erro não serão importados caso você opte por prosseguir agora. Para corrigir:

  1. Baixe a planilha através do botão acima. Ela contém todos os registros originais.
  2. Verifique a nova coluna "Motivo do Erro" e corrija os dados incorretos.
  3. Mantenha os registros que já estavam corretos inalterados.
  4. Importante: Exclua a coluna "Motivo do Erro" antes de salvar.
  5. Utilize a opção "Substituir planilha" no topo desta tela para enviar o arquivo corrigido.
